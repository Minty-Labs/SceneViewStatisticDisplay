# Mesh Stats
View various mesh data in your scene view of your selected game object<br>
Displays
- Number of Basic Meshes (MeshRenderer)
- Number of Skinned Meshes
- Vertice Count
- Triangle Count
- Sub-Mesh (Draws) Count
Also has an option to show VRChat's Avatar Performance Rating Colouring
